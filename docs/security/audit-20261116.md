## 4. 直し方の案（第3段は未着手。持ち主が頼んでから）

- **P1**: 旗を CMake の真偽で書き直す。案 A（推奨）: `-DENABLE_LIBJPEG=OFF -DENABLE_LIBOPENJPEG=OFF -DENABLE_BROTLI=OFF -DENABLE_HARFBUZZ=OFF`
  にして decoder を入れない。本文の抽出は画像を使わない。インライン画像の後ろは `EI` を探して読み直すので本文は続く
  （入れる前に `sync-verify.sh` で出力が変わらないことを確かめる）。案 B: 部品を残すなら旗を `ON` と明記し、コメントを直し、
  `security-assessments.json` の `gaps` に Homebrew の部品を足す。どちらでも、`build-pdftotext.sh` の最後に `otool -L` で
  意図しない部品が無いことを確かめる行を足す。
- **P2**: 段落の切れ目の判定で使う「次の本文の語」と「fragment の属する行」を、ループの前に 1 回ずつ前後から求めて配列に持つ（O(n)）。
  出力は変わらないので、`sync-verify.sh` と同じ比較で確かめられる。
- **P3**: 上流の署名鍵（`CA262C6C83DE4D2FB28A332A3A6A4DB839EAA6D7`、上流の README・リリースの告知で照合）を入れ、`fork-sync.py` で
  merge の前に `git verify-tag` を通す。通らなければ止めて知らせる。
- **P4**: `$CACHE` の名前が `poppler-baseline` で終わることを確かめ、消すのは 40 桁の 16 進の名前のフォルダだけにする。
- **P5**: PDFViewer の台本に Zeteion と同じ `git status --porcelain --untracked-files=no` の検査を足す（PDFViewer の repo で）。
